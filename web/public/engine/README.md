# Moteur d'échecs

`stockfish-19-lite-single.js` et `.wasm` : [Stockfish.js](https://github.com/nmrugg/stockfish.js) 19.0.1
(paquet npm `stockfish`), version « lite » à un seul fil, qui tourne dans un Web Worker sans configuration
serveur particulière. Basé sur [Stockfish](https://github.com/official-stockfish/Stockfish).
